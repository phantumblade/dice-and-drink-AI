## 📖 Panoramica del Progetto

**Dice & Drink Modern** è un'applicazione web completa progettata per rivoluzionare l'esperienza di gestione e frequentazione di un gaming pub. La piattaforma collega il mondo fisico del gioco sociale con la comodità digitale, offrendo un'interfaccia intuitiva che permette ai clienti di prenotare tavoli, partecipare a tornei e gestire le proprie campagne di Dungeons & Dragons, fornendo al contempo agli operatori strumenti amministrativi potenti ed efficienti.

### 🎨 Design "Neo-Moderno"

L'applicazione si distingue per un linguaggio visivo accattivante che combina:
- **Colori vibranti** e palette dinamiche per catturare l'attenzione
- **Effetto glassmorphism** per un aspetto contemporaneo e sofisticato
- **Animazioni fluide** che rendono ogni interazione piacevole e naturale
- **Interfaccia immersiva** che trasforma la gestione quotidiana in un'esperienza coinvolgente

## ✨ Funzionalità Principali

### 🔐 Sistema di Autenticazione Avanzato

Un sistema di gestione utenti completo con controllo degli accessi basato sui ruoli (RBAC).

**Caratteristiche:**
- **Gestione Ruoli**: Quattro livelli di accesso (Ospite, Cliente, Staff, Amministratore)
- **Profili Personalizzabili**: Avatar personalizzati, statistiche utente e preferenze salvate
- **Sicurezza**: Autenticazione JWT con token sicuri e protezione delle password
- **Privacy**: Gestione completa dei dati personali conforme alle normative

### 🏆 Sistema Tornei Completo

Un ecosistema integrato per organizzare e gestire competizioni di gioco.

**Cosa puoi fare:**
- **Sfoglia & Iscriviti**: Trova tornei filtrando per tipologia (Standard, D&D, Party, Blitz)
- **Gestione Slot**: Sistema intelligente di prenotazione posti con limiti personalizzabili
- **Pannello Amministrativo**: Crea, modifica ed elimina tornei con facilità
- **Visualizzazioni Dinamiche**: Card colorate con indicatori di stato in tempo reale
- **Indicatore Urgenza**: Segnalazione visiva per tornei in chiusura (3-7 giorni)
- **Notifiche**: Aggiornamenti automatici su iscrizioni e modifiche ai tornei

**Tipologie di Torneo:**
- 🎯 **Standard** - Tornei classici di giochi da tavolo
- 🐉 **D&D** - Competizioni e one-shot di Dungeons & Dragons
- 🎉 **Party** - Eventi sociali e giochi di gruppo
- ⚡ **Blitz** - Tornei veloci e intensi

### 🐉 Tracker Campagne D&D

Strumenti specializzati per Dungeon Master e avventurieri, tutto in un unico posto.

**Gestione Campagne:**
- **Creazione Campagna**: Imposta nome, descrizione, lore e ambientazione
- **Note Condivise**: Sezione note per tenere traccia di eventi importanti e dettagli
- **Registro Sessioni**: Documenta ogni sessione con data, sommario e momenti memorabili
- **Dashboard Visiva**: Panoramica completa con statistiche e progressi

**Gestione Personaggi:**
- **Schede Dettagliate**: Nome, classe, razza, livello e statistiche complete
- **Status Vitale**: Traccia personaggi attivi o caduti in battaglia
- **Associazione Campagne**: Collega personaggi a campagne specifiche
- **Storia del Personaggio**: Note biografiche e progressione narrativa

**Pianificazione Sessioni:**
- **Calendario Integrato**: Programma sessioni future con date e orari
- **Sommari Post-Sessione**: Documenta cosa è successo dopo ogni incontro
- **Timeline**: Visualizza la cronologia completa della campagna

### 🛍️ Catalogo Digitale & Sistema di Prenotazione

Sistema di ordinazione e prenotazione semplificato e moderno.

**Catalogo Prodotti:**
- **Categorie Multiple**: Giochi da tavolo, bevande, snack e merchandise
- **Filtri Avanzati**: Cerca per nome, categoria o fascia di prezzo
- **Card Visive**: Immagini, descrizioni e prezzi chiari per ogni prodotto
- **Disponibilità**: Indicatori in tempo reale dello stock disponibile

**Sistema di Prenotazione:**
- **Prenotazione Tavoli**: Seleziona data, ora e numero di posti
- **Calendario Interattivo**: Visualizza disponibilità e slot già prenotati
- **Conferma Immediata**: Ricevi feedback istantaneo sulla tua prenotazione
- **Gestione Prenotazioni**: Visualizza, modifica o cancella le tue prenotazioni

**Carrello Intelligente:**
- **Gestione Unificata**: Prodotti e prenotazioni nello stesso carrello
- **Calcolo Automatico**: Prezzi totali e tasse calcolati in tempo reale
- **Salvataggio Sessione**: Il carrello persiste tra le sessioni
- **Checkout Guidato**: Processo di pagamento semplice e sicuro

### 📊 Dashboard Amministrativa

Centro di controllo completo per proprietari e gestori del locale.

**Analytics & Metriche:**
- **Grafici Revenue**: Visualizza entrate giornaliere, settimanali e mensili
- **Crescita Utenti**: Monitora nuove iscrizioni e utenti attivi
- **Prodotti Popolari**: Identifica gli articoli più venduti e richiesti
- **Statistiche Tornei**: Analizza partecipazione e tipologie preferite

**Pannelli di Gestione:**
- **Gestione Utenti**: Visualizza, modifica ruoli e gestisci account
- **Gestione Contenuti**: CRUD completo per prodotti, tornei e campagne
- **Controllo Prenotazioni**: Monitora e gestisci tutte le prenotazioni
- **Impostazioni Sistema**: Configura parametri globali dell'applicazione

**Azioni Rapide:**
- Pulsanti di accesso veloce alle funzioni più utilizzate
- Notifiche per azioni che richiedono attenzione
- Export dati per analisi esterne
- Backup e restore database

## 🚀 Guida all'Installazione

Segui questi passaggi per avviare una copia locale del progetto.

### 📋 Prerequisiti

Prima di iniziare, assicurati di avere installato:
- **Node.js** (versione 18 o superiore) - [Scarica qui](https://nodejs.org/)
- **npm** (incluso con Node.js) o **yarn** come package manager alternativo
- **Git** per clonare il repository - [Scarica qui](https://git-scm.com/)

### 📥 Installazione Passo-Passo

#### 1️⃣ Clona il Repository

```bash
git clone https://github.com/phantumblade/dice-and-drink-AI.git
cd dice-and-drink-AI
```

#### 2️⃣ Installa le Dipendenze Frontend

```bash
npm install
```

#### 3️⃣ Installa le Dipendenze Backend

```bash
cd server
npm install
cd ..
```

#### 4️⃣ Configurazione Ambiente

Crea i file di configurazione necessari:

**File `.env.local` nella directory principale (Frontend):**
```env
VITE_GEMINI_API_KEY=la_tua_chiave_api_gemini
VITE_API_URL=http://localhost:3000
```

**File `.env` nella directory `server` (Backend):**
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET=il_tuo_segreto_jwt_super_sicuro
PORT=3000
NODE_ENV=development
```

#### 5️⃣ Inizializza il Database

```bash
cd server

# Crea le tabelle del database
npx prisma migrate dev --name init

# (Opzionale) Popola con dati di esempio
npm run seed

cd ..
```

#### 6️⃣ Avvia l'Applicazione

Apri **due terminali separati**:

**Terminale 1 - Backend:**
```bash
cd server
npm run dev
```
Il server partirà su `http://localhost:3000`

**Terminale 2 - Frontend:**
```bash
npm run dev
```
L'applicazione sarà disponibile su `http://localhost:5173`

### 🎉 Primo Accesso

Una volta avviata l'applicazione:
1. Apri il browser su `http://localhost:5173`
2. Registra un nuovo account o usa le credenziali di test (se hai eseguito il seed)
3. Esplora le funzionalità disponibili in base al tuo ruolo
